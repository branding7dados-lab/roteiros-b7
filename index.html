Falta ligar o banco

O sistema está no ar, mas ainda não sabe onde guardar os roteiros. Abra o arquivo js/config.js e cole os dois valores do seu projeto no Supabase:

window.B7_CONFIG = {
  SUPABASE_URL: 'https://xxxxx.supabase.co',
  SUPABASE_PUBLISHABLE_KEY: 'eyJhbGci...'
};

Os dois estão em Supabase → seu projeto → Project Settings → API: Project URL e a chave anon / publishable. Nunca use aqui a service_role — ela é secreta e este arquivo fica visível para quem abrir o site.

Antes disso, rode o supabase_setup.sql no SQL Editor para criar as tabelas. O passo a passo completo está no README.md.
